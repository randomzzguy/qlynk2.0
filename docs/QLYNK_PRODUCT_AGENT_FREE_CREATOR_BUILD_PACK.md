## Application, backup and restore

The new **Qlynk product information update** panel appears only in the product account's Knowledge Base. Review the facts, instruction changes and affected sources; then choose **Apply reviewed facts to agent**. The API accepts only the server-generated pack, checks authenticated ownership and the review fingerprint, and refuses a changed instruction version. SQL applies archives, new facts and a versioned instruction save in one transaction. Other account owners cannot use this update.

The backup is private to the owner and service role. **Undo product update** restores original source content/activity and instructions as a new prompt version, then archives the replacement sources. It does not delete knowledge. Applying the pack again without undo is refused so the original backup survives. Undo restores old pricing, so use it only during a coordinated rollback and then supply current facts before allowing public answers.
