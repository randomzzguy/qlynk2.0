## 1. Founder launch post

Qlynk is now open source. And the Creator plan is free forever.

I've been thinking about what would make Qlynk more useful to more people.

There are plenty of AI tools to choose from. I want people to be able to try what I've built, see how it works, and help make it better.

So I'm opening up the source under the MIT license and making Creator free, with no credit card and no expiry.

With Creator, you can:

• Build one focused AI agent from your own knowledge.
• Add documents, links, facts and FAQs.
• Set its scope, tone and response rules.
• Share a public link or embed it on your website.
• Use 5,000 messages each month.

Agency stays optional: $38/month or $360/year for 10,000 monthly messages and removal of the Qlynk attribution.

You can use the hosted app, or explore the code and run your own deployment. Self-hosting uses your own infrastructure and AI provider credentials, so those costs still apply.

I'd love to hear what you build, what gets in your way, and what you'd improve.

## 3. Open-source community follow-up

I've opened up Qlynk under the MIT license.

If you're a developer who wants to see how a focused AI agent app works, the code is there to explore, modify and build on.

Qlynk lets people add their own knowledge, set the agent's scope and response rules, and share it through a public page or website widget.

The app uses Next.js, React, Supabase and Groq. The repository includes setup instructions, database migrations, an environment example and contribution guidance.

You can run your own deployment with your own infrastructure and provider credentials. Hosting and AI usage can still incur costs.

If you spot a bug, find confusing setup steps or have an idea that would make the app more useful, I'd welcome an issue or contribution. Please keep credentials and private data out of public issues.

The hosted Creator plan is also free forever if you just want to try it.
